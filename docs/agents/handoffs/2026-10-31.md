## Decisions on 2026-10-31

The maintainer withdrew the 2026-10-30 decision to package SpamAssassin:

- ArzoieMail never builds or ships SpamAssassin or ClamAV. Both stay optional integrations
  that administrators install themselves, on Windows or on another server such as Linux.
  Connecting them must be easy.
- The default spam filtering becomes native: a Bayesian filter trained from IMAP Junk moves,
  plus content rules.
- Microsoft Defender (bundle 5) provides built-in antivirus.

rules, which need a schema change on all four databases). The decision is recorded in the

## Gotchas found

- Shell heredocs mangle backslash escapes in code (`\r\n`, `\\`, `\t`); write edit scripts to
  files with the file tool.
- `panel.js` functions share one scope; check a name is unused before adding a helper.
- Browser selectors by label can also match the hidden sign-in form; scope them to `#content`.
- The service may run as the restricted `NT SERVICE\hMailServer` account. Folders the service
  must see, such as backup destinations, need its access.
- The default IMAP hierarchy delimiter is `.`.
- DKIM signing happens before local and external delivery split, so local mail from a signing
  domain is signed too. The conformance test relies on that.
- DKIM key generation runs inside a management request, which times out after 10 seconds and
  blocks the single-threaded pipe; 3072-bit keys outlasted it on slower CI backends.
- Spam tests only run where the client's IP range has spam protection; the default range for
  127.0.0.1 has none, so a live scoring test needs a temporary higher-priority range.
- Reason headers (`X-hMailServer-Reason-N`) are written only when a message is classified as
  spam.
- Shell heredocs also turned `\x00` and `\r\n` in Python replacement strings into real control
  characters; write such edits as script files.
