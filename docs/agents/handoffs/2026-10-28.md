## Delivered scope in this branch

- Queue metadata/search, bounded recipient inspection, retry/removal and due-mail wake.
  Server administrators only. Decimal-string IDs retain 64-bit precision. No bodies, paths
  or bulk clear endpoint. Stored mail is excluded; busy delivery returns 409. Native mutations
  and delivery reservation share a guard and invalidate pending snapshots. Legacy COM single-item
  queue methods use the same guards. Listing still scans queue metadata; indexed paging and
  measured capacity remain follow-ups.
- Routes and allowed recipients. Server administrators only; exact parent IDs, validated
  domains/hosts/ports, required STARTTLS/listed-recipient defaults. Passwords are write-only;
  omission preserves them, explicit clearing requires authentication off. Authentication
  requires implicit TLS or required STARTTLS. Changes affect delivery immediately.
- Global and scoped mailbox rule builders. Global rules require server administrator;
  mailbox rules retain owning-domain/protected-account checks. New definitions are disabled;
  active rules must be disabled before editing and enabled separately. At most 20 criteria
  and 20 ordered actions. Regex, scripts and local binding are excluded. Header writes cannot
  replace engine/authentication/MIME structural headers. Route actions require server admin.
  Checked persistence disables first and checks children before activation; it is not a
  rollback transaction. Infrastructure failures can leave a disabled partial draft to repair.
- Native, HTTP/CSRF/origin, browser and real loopback SMTP/POP3 regressions. The new NUnit
  queue boundary regression failed against the original VM binary before fixed-server testing.
  Local fixture traffic only; no external SMTP delivery.
