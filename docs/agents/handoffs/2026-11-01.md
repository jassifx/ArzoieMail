## Design points for review

- **Renewal automation scope:** the API renews without an administrator's password, through a
  credential-less scope the pipe accepts only from the configured API identity. It is limited to
  certificates an administrator issued with automatic renewal.
- **Applying certificates restarts the mail services** (listeners build their TLS context at
  start). Automated renewal does this itself when the certificate is in use.
- **The panel is installed by default** in a full installation, listening on 8443 and, when free,
  80 for ACME. Setup opens no firewall port.

## Gotchas found

- Listener TLS contexts are built once, when the listener starts; live connections reference the
  context, so it is not swapped under them.
- Pebble's release zips contain only the executables; the test generates Pebble's own HTTPS
  certificate and configuration.
- A PowerShell script block used as an HTTPS validation callback can run on a thread without a
  runspace; check certificates with a synchronous handshake instead.
