This page describes how to install the ArzoieMail client tools. If you want to manage your ArzoieMail installation remotely, you need to install the ArzoieMail client tools on the computer you want to manage your installation from.

1. Start the ArzoieMail installation program and click Next in the welcome dialog.
2. Choose where you want to install the client tools and click Next.
3. In the *Select components* page, de-select *Server*.
4. Click *Next* until the installation has finished.
