## ArzoieMail hosting information

ArzoieMail is an e-mail server. This means that it is a software, which runs on a computer, which can be used by companies, organizations and individuals to host e-mail messages. hMailServer.com does not provide any email services, just the software which are used to create e-mail services.

If you have issues with ArzoieMail, but have not installed it yourself, you should contact the administrator of the email server. If you have your own domain name, the administrator is typically the company you pay every month/quarter/year for the services.
