### What is "ArzoieMail Password"?

When you connect to ArzoieMail using ArzoieMail Administrator, and when you perform a database upgrade, you will be prompted for the ArzoieMail Password.

This is the password for your ArzoieMail installation, which you set during the installation process. This password may have been changed later using ArzoieMail Administrator, under *Settings - Advanced*.

Please note that this is not the same as the password for your database.
